# 데이터 준비

원본·가공 레코드는 공개 저장소에 포함하지 않았습니다. 분석 당시 사용한 입력 파일은 [입력 목록](input_manifest.json)에 기록했습니다.

- VDS 교통류와 사고·급감속 집계
- ASOS 기상 관측
- 도로 중심선 SHP와 IC 위치
- 교량·터널·시설물 위치·속성
- 사고차량 종류 보조 자료

자료별 원 배포 URL·라이선스가 제공 폴더에 정리되어 있지 않아 임의의 출처 링크나 재배포 허가를 기재하지 않았습니다. 한국도로공사 연계 수업 자료와 기상·도로 자료는 사용 권한에 맞게 별도로 확보해야 합니다.

기본 폴더는 저장소 루트의 `data/`입니다. `data_mart.csv`, `data_mart_final_features_v2.csv`, `model_outputs/model_sample_data.csv`도 이 폴더 안에서 생성·사용합니다. `.gitignore`로 실제 데이터가 추적되지 않도록 했습니다.

최종 데이터마트는 제공 집계 결과 기준 11,704,666행입니다. 대용량 원본 전체를 이번 정리 과정에서 다시 읽거나 집계하지 않았습니다. 필요한 정량 결과는 `results/eda/overall_event_rate.csv`와 모델 결과 CSV를 대조했습니다.
